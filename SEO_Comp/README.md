# SEO_Comp — lessons from competitor and SEO research on Grizzly

One lesson per file. Update a file rather than adding a duplicate; delete one that turns out wrong.

- [L&I open-data query syntax](lni-open-data-query-syntax.md) — `$q=` now returns null rows; use the field filter or `$where`
- [Grizzly city pages are near-duplicates](grizzly-city-pages-are-near-duplicates.md) — 16 pages 98.4% identical, 15 placeholder titles, Lynnwood H1 reads "in L, WA"
- [Kirkland and Lynnwood are separate markets](kirkland-and-lynnwood-are-separate-markets.md) — only two firms rank in both cities' landscaping packs
- [Ranking page shape is service + city](ranking-page-shape-is-service-plus-city.md) — one service, one city, both in the title; hubs and multi-service city pages do not rank
- [AEO barely exists in this market](aeo-generative-answers-barely-exist-in-this-market.md) — one generative answer across seven query/engine combinations
- [The /pavers URL is a 404 that still ranks](grizzly-pavers-url-is-a-404-that-still-ranks.md) — ranks ~#3 on the paver-cost query with a priced snippet, returns 404
- [Verify similarity numbers twice](verify-similarity-numbers-twice.md) — a diff idiom doubled a figure and a wc idiom inflated word counts 10%, both flattering the subject
- [Google's index holds Grizzly's old site](grizzly-google-index-holds-the-old-site.md) — only dead Kirkland-era URLs indexed; zero current URLs; no canonicals
- [Northern Waters' 4-page site outranks Grizzly](northern-waters-four-page-site-outranks-grizzly.md) — page count is not the irrigation lever; entity age, "sprinkler" vocabulary and certs are
